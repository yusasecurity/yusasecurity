### Prompt-injection firewall for AI agents.

Your agent reads webpages, tweets, token descriptions, tool results and other people's skill files. Any of them can carry an order. Some of those orders are written in characters no font draws, so you never see them. The model does.

YUSA reads text the way the model reads it, shows you what was hidden, and stops a hijacked agent before it moves money or leaks a key.

| | |
|---|---|
| **Unmask** | Unicode TAG smuggling, zero-width splits, look-alike letters, hidden HTML, base64 |
| **Score** | 25 injection rules and 10 secret formats. Anything in a hidden layer is a block |
| **Fence** | Untrusted text wrapped in a per-call random nonce tag |
| **Gate** | Every tool call checked: tool, recipient, host, value cap, unlimited approvals |

No dependencies, no network, no keys. Runs in the browser, in Node, as a CLI, and as an [Aeon](https://www.aeon.fun) skill.
